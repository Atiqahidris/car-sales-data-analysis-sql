# Car Sales Data Analysis using SQL

## 📌 Project Overview

This project demonstrates how SQL can be used to analyze a car listing dataset and answer business-related questions. The analysis focuses on vehicle listings, sales performance, and data quality by applying SQL queries to extract meaningful insights.

## 🎯 Objectives

* Analyze car listing and sales data using SQL.
* Answer business questions through data querying.
* Summarize sales performance by brand.
* Identify incomplete or missing records.
* Generate insights to support business decision-making.

## 📊 Dataset

* **Dataset:** Car Listing
* **Source:** Public dataset for SQL learning and practice.

## 🛠️ Tools & Technologies

* Microsoft SQL Server
* SQL

## 💻 SQL Concepts Applied

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* CASE WHEN
* Aggregate Functions (SUM, AVG, COUNT)
* DATEDIFF

## 📈 Business Questions Answered

* Listed all cars that have not been sold.
* Retrieved all vehicles from Brand-C.
* Identified cars with missing first listing dates.
* Found cars that were listed but remain unsold.
* Retrieved cars sold within 60 days of listing using the DATEDIFF function.
* Identified cars that were sold without being listed.
* Calculated the total number of cars sold.
* Counted the total number of cars for each brand.
* Compared sold and unsold vehicles by brand.
* Determined the brand with the highest number of listed vehicles.
* Calculated the average number of days required to sell a listed car.
* Identified incomplete records with missing information.

## 🔍 Key Findings

* Sales performance varied across different vehicle brands.
* Brand-level comparisons highlighted differences in listing and sales activity.
* Data quality checks identified incomplete records that may affect reporting accuracy.
* SQL queries enabled efficient extraction of business insights from structured data.
